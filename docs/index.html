Catálogo de Cursos – Visão geral

Aplicação web para consultar, pesquisar, filtrar e ver detalhes de cursos de um ambiente educacional (Moodle fictício), com front-end baseado no protótipo SESI+Indústria do Figma, API em C#/.NET e banco SQLite.

NotaNão há integração com Moodle nem cadastro, edição ou exclusão de cursos. Todos os dados são fictícios.

O que a aplicação faz

  • Lista cursos por meio da API.
  • Pesquisa pelo nome e filtra por categoria, modalidade ou status, combinando pesquisa e filtros.
  • Mostra a quantidade de resultados, permite limpar os filtros e exibe mensagens de carregamento, erro e nenhum resultado.
  • Abre o detalhe do curso e a Área do aluno com módulos, aulas e progresso.

Páginas

RotaArquivoDescrição

Arquitetura

Um único projeto ASP.NET Core serve o front-end estático (wwwroot) e a API REST (/api). O JavaScript consome a API com fetch; a API consulta o SQLite pelo Entity Framework Core.

Navegador ──GET /cursos.html──────▶ Arquivos estáticos (wwwroot)
Navegador ──fetch /api/cursos?...─▶ Minimal API (Program.cs)
                                       │ EF Core (LINQ)
                                       ▼
                                  SQLite (cursos.db)
Navegador ◀──JSON (camelCase)─────────┘

Executar o projeto

Como rodar a aplicação localmente, com ou sem Docker.

Requisitos

  • .NET 8 SDK (confira com dotnet --version; deve começar com 8.).
  • Internet na primeira execução, para restaurar o pacote do EF Core.

Com o .NET

cd CursosApp
dotnet run

Abra a URL exibida no terminal (por exemplo, http://localhost:5000). O banco é criado e populado automaticamente.

AtençãoAbra o site pelo endereço do dotnet run. Abrir index.html direto do disco impede o carregamento dos cursos, pois o front-end depende da API.

Com Docker

docker build -t cursos-app .
docker run -p 8080:8080 cursos-app

Acesse http://localhost:8080.

Mudar a porta

dotnet run --urls http://localhost:5050

Configuração do banco

O projeto usa SQLite, banco relacional de código aberto em um único arquivo, sem servidor.

Criação e carga inicial

Na inicialização, Program.cs chama EnsureCreated(), que cria cursos.db e as tabelas se não existirem, e Seed.Run(db), que insere os cursos fictícios apenas se a tabela estiver vazia.

Connection string

ItemValor
PadrãoData Source=cursos.db
Variável de ambienteConnectionStrings__Default

Zerar os dados

Pare o servidor, apague cursos.db e rode de novo. Isso também é necessário depois de alterar o seed em Data.cs.

NotaNão há migrations: o esquema é criado por EnsureCreated. Para evoluir o esquema, adote dotnet ef migrations add.

Front-end: páginas e acessibilidade

HTML, CSS e JavaScript puros, sem frameworks, seguindo o protótipo do Figma (Open Sans, vermelho SESI, bege e vinho).

Organização do JavaScript

O arquivo wwwroot/js/app.js é compartilhado por todas as páginas. O atributo data-page do <body> define qual função executa:

data-pageFunçãoResponsabilidade
homehome()Carrossel de cursos e depoimentos.
catalogocatalogo()Pesquisa, filtros, contagem e estados de interface.
cursocurso()Detalhe do curso e barra fixa.
avaava()Aulas, busca e progresso (salvo em localStorage).

Estados de interface

Carregando (role="status"), erro (role="alert" com botão “Tentar novamente”), nenhum resultado e sucesso com a contagem em uma região aria-live.

Responsividade

CSS Grid com auto-fill/auto-fit, Flexbox, carrosséis com scroll-snap e uma única coluna abaixo de 800 px.

Decisões de acessibilidade

  • HTML semântico e link “Ir para o conteúdo”.
  • Campos com label, foco visível e aria-current na aula atual.
  • Acordeões com <details> e carrosséis acessíveis por teclado, com botões rotulados.
  • Status e progresso também em texto, não só por cor; alt nas imagens informativas.
  • Respeito a prefers-reduced-motion.

Publicação

Como gerar os arquivos de publicação e colocar a aplicação no ar gratuitamente.

Arquivos de publicação (ZIP)

dotnet publish -c Release -o publish

Compacte a pasta publish em um arquivo ZIP.

Render (Docker)

  1. Suba o projeto no GitHub.
  2. No Render, escolha New → Web Service e conecte o repositório.
  3. Selecione Docker e o plano Free, e crie o serviço.
  4. Se não responder, defina a variável PORT=8080.
AtençãoNo plano gratuito do Render o serviço dorme após cerca de 15 minutos sem acesso, e o primeiro acesso seguinte pode levar cerca de um minuto. Confira os limites atuais na página de preços.

O banco é recriado e repopulado a cada reinício, o que não afeta a aplicação, pois os cursos vêm do seed.

API REST

Três endpoints de leitura, em JSON com propriedades em camelCase. Implementados em Program.cs com Minimal API.

GET/api/cursos

Lista os cursos, com pesquisa e filtros combináveis.

Sintaxe

GET /api/cursos?busca=&categoria=&modalidade=&status=

Parâmetros

NomeTipoDescrição
buscastring, opcionalTexto procurado no nome completo e no nome breve, sem distinção de maiúsculas e acentos.
categoriastring, opcionalIgualdade exata, por exemplo Matemática.
modalidadestring, opcionalEaD ou Presencial.
statusstring, opcionalDisponível, Em breve ou Encerrado.

Valor retornado

200 OK com o total e a lista, ordenada pelo nome.

{
  "total": 1,
  "itens": [{
    "id": 1,
    "nomeCompleto": "Matemática para a Precisão: Medidas e Escalas na Metalurgia",
    "nomeBreve": "Matemática da Precisão",
    "resumo": "Aplicação de grandezas, proporções e escalas...",
    "categoria": "Matemática",
    "modalidade": "EaD",
    "cargaHoraria": 40,
    "status": "Disponível",
    "imagemUrl": "/img/hero-image.jpg",
    "dataDisponibilizacao": "2026-01-05"
  }]
}

GET/api/filtros

Retorna os valores existentes para preencher os filtros.

{ "categorias": ["Ciências da Natureza", "Linguagens", "Matemática", "Sustentabilidade"],
  "modalidades": ["EaD", "Presencial"],
  "status": ["Disponível", "Em breve", "Encerrado"] }
NotaA pesquisa normaliza o texto (remove acentos e converte para minúsculas), então “matematica” encontra “Matemática”. A filtragem é feita em memória, adequada para um catálogo pequeno.

Limitações e uso de IA

Limitações conhecidas

  • O design foi feito a partir de capturas do Figma, não do arquivo; espaçamentos e detalhes podem diferir.
  • Só 3 fotos foram fornecidas, então elas se repetem entre os cursos. O vídeo do hero não foi fornecido (imagem estática).
  • “Matricule-se” abre a Área do aluno em modo de demonstração, sem login; o progresso fica no localStorage do navegador.
  • Links do rodapé (termos, redes sociais) são ilustrativos.
  • Sem migrations, paginação e testes automatizados; a integração com Moodle não foi feita.
  • Em contêiner, o SQLite é recriado a cada reinício.

Uso de Inteligência Artificial

O Claude (Anthropic) foi usado para gerar a base do código e adequá-la ao enunciado e ao Figma. Finalidade, prompts, validação e erros encontrados estão em USO_DE_IA.md.
